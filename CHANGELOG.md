# Changelog

All notable changes to imgx will be documented here.

## [Unreleased]

### Added

- Cross-platform classical image-processing CLI architecture.
- PNG, JPEG, GIF, BMP and TIFF output.
- WebP input decoding.
- Resize, crop, rotate, flip, grayscale, brightness, contrast, blur, sharpen, border, watermark, compress, info and batch commands.
- stdin/stdout pipeline support.
- Decode-size safety guard.
- CI and GoReleaser release automation.
